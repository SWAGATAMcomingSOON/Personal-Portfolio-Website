# OASIS INFOBYTE — Web Development & Designing
## Level 1 · Task 2: Personal Portfolio

A responsive personal portfolio website built with HTML5, CSS3, and a small amount of vanilla JavaScript for the mobile navigation. It is designed as a student developer portfolio and includes a hero/profile area, About Me, skills, two project cards, contact links, and smooth scrolling.

## Files
- `index.html` — page content and sections
- `styles.css` — colours, layout, responsive breakpoints, and visual design
- `script.js` — mobile menu interaction and automatic footer year

## Run locally
1. Download and extract the project folder.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. Resize the browser to test the mobile layout.

The Google Fonts import requires internet access. The site does not require a build step or package installation.

## Before publishing
Personalise these starter details:

- Replace the generic GitHub and LinkedIn URLs with your actual profile/repository links.
- Add a real profile photo if you want one; the current SD avatar is a placeholder.
